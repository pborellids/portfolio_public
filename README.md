# Data Science & Analytics Portfolio

Este repositório centraliza meus projetos, estudos e experimentos na área de Ciência de Dados, Machine Learning e automação com Python. Como professor e engenheiro, utilizo este espaço para documentar resoluções de problemas complexos e metodologias de ensino de IA.

## 📂 Estrutura do Repositório

### 1. [Matriz de Confusão](./Matriz%20de%20Confusão)
Estudo focado em métricas de avaliação de modelos de classificação.
* **Objetivo:** Analisar o desempenho de modelos através de matrizes de confusão, acurácia, precisão e recall.
* **Tecnologias:** Python, Scikit-learn, Matplotlib.

### 2. [Incerteza Transformada em Certeza](./incerteza_transformada_em_certeza)
Projeto prático envolvendo visualização de dados e métricas estatísticas.
* **Conteúdo:** Scripts para geração de curvas ROC-AUC e análise de distribuições.
* **Destaque:** Implementação de visualizações customizadas para facilitar a interpretação de resultados probabilísticos.

## 🛠️ Configuração do Ambiente
O projeto utiliza um ambiente virtual único localizado na raiz para garantir a consistência das bibliotecas entre todos os subprojetos.

**Principais bibliotecas utilizadas:**
* Pandas & NumPy (Manipulação de dados)
* Scikit-learn (Machine Learning)
* Matplotlib & Seaborn (Visualização de dados)
